# PokéGo — working notes

PokéGo is this user's own version of PokéSurvivor (JPTER78/pokesurvivor, imported at
upstream commit 018e986). Code comments, docs and the source-language UI text are in Spanish.

## Build
1. Edit `dev.html` (never `index.html`, which is generated) and the files under `js/`, `css/` and `tools/`.
2. `node tools/build.js && node tools/export_data.js && python tools/make_seo_pages.py`
   - `build.js` writes `index.html`, `js/app.min.js`, `js/lang/*.js` and `version.json`.
     `js/core/updater.js` reloads players when `version.json` changes, so keep both.
   - `make_seo_pages.py` writes `en/`, the guide/data pages, `404.html`, `robots.txt` and `sitemap.xml`.
3. `node --test tests/i18n.test.cjs tests/net.test.cjs tests/items.test.cjs tests/save.test.cjs tests/auto.test.cjs tests/audio.test.cjs tests/arceus.test.cjs tests/orbs.test.cjs tests/mobile.test.cjs tests/coop.test.cjs` (all must pass).
4. Run locally: `python -m http.server 8123` → http://localhost:8123 (`/dev.html` for unminified code).

## Android app (separate from the web)
- `app/` is a Capacitor project that ships the same built game (`index.html` + `js/app.min.js`);
  see `docs/APP.md`. After the web build: `cd app && npm run apk` →
  `app/android/app/build/outputs/apk/debug/app-debug.apk` (needs JDK 21 + Android SDK, both installed).
- App-only behaviour lives in `js/core/native.js` and is gated by `G.Native.app` (back button, links,
  share instead of download; no service worker, updater, fullscreen, Google sign-in or Google Drive).
  Web-only features must keep working when `G.Native.app` is false.
- `app/www/` is generated by `tools/build_app.js` (not in git). Bump `versionCode` in
  `app/android/app/build.gradle` for each APK handed out.

## Offline play
- The Firebase SDK ships in `js/vendor/firebase/` (never load it from a CDN again). With no connection,
  `db.js` opens the account from its copy on the device (`ps.cloud.<uid>`), and the `online` event uploads it,
  merged with the cloud. On the web, Settings > Account > "Descargar imágenes" fills `sw.js`'s sprite cache.
- To test it without touching the live project: `npx firebase-tools emulators:start --only auth,firestore,database
  --project pokego-ec220` and a copy of `dev.html` that sets `G.FIREBASE_CONFIG.emulator = true` after
  `firebase-config.js`. Never create test accounts on the live project.

## Text and translations
- Spanish strings are the dictionary keys. Changing Spanish text means changing the same key in
  `js/data/lang-en.js`, `lang-fr.js`, `lang-it.js`, `lang-pt.js`, `lang-zh-cn.js`, `lang-zh-hant.js`
  and `lang-updates.js`. New text: add it to `lang-en.js` plus a row in `lang-updates.js`.
  `node tools/build_langs.js --faltan` lists gaps.
- Gameplay changes and fixes go in `js/data/changelog.js` (Spanish + English, today's date).
  Entries before 2026-10-20 are PokéSurvivor's history: keep its name there and in their translations.
